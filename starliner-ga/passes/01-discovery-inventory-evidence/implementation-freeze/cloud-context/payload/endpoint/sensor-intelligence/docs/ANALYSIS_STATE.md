   pre-resolution endpoint input must not invent one.
2. Inspected Starliner delivery wrapper and reference validator/outbox paths
   disagree.

4. Current entity/finding signal taxonomies omit endpoint concepts.
5. Sensor enrollment, tenant-bound credentials and capability certification
   are not defined in the current endpoint.

## Recommended architecture

Small typed in-process capture bridges in System Monitor, hooks, proxy and
enforcer feed one host-local endpoint adapter. The adapter owns enrollment,
privacy filtering, validation, deterministic source IDs, compound manifest,
partitioned durable outbox, delivery/replay/health and command routing.
Starliner owns admission, canonical identity, cross-sensor correlation,
findings, policy authority, product materialization and evidence authorization.
