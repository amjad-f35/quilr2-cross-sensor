# Feature and capability merger

## Counts

- 18 source features;
- 18 logical MCP contribution capabilities.

The one-to-one logical capability rows preserve source feature identity until
a later five-profile merger can create genuine shared capabilities.

## Capability families

The source-grounded catalog includes:

- observe runtime construction and lifecycle;
- backend discovery and selected tool discovery;
- Direct tool-call observation;
- safe identifier and actor transformations;
- record mapping and current contract validation;
- bounded SQLite outbox;
- HTTP delivery, partial result handling, retry, terminalization, and health;
- manifest, self-test, metrics, and operational routes;
- legacy pre-tool policy evaluation;
- supporting workflow/registry surfaces identified as adapter candidates.

## Reachability rules

No source implementation is labeled `ENABLED_AND_REACHABLE` merely because it
exists. Optional Starliner dependencies, configuration, private packages,
external services, and deployment flags result in
`CONFIGURATION_DEPENDENT`.

## Unique MCP evidence

MCP Gateway uniquely contributes:

- registered backend/server definitions;
- tools and partial capability inventory;
- actual gateway-observed tool calls;
- gateway-native DLP/policy/confirmation effect context;
- MCP session/protocol logs and rejected requests;
- outbox/delivery health.

It does not provide authoritative enterprise person, device, Endpoint process,
model-provider, or general SaaS identity.
