# Product Surface Recommendations

| Product area | Default display | Drill-down | Action |
| --- | --- | --- | --- |
| Inventory | canonical candidate with source badges/readiness | source fields/profile/evidence | resolve/configure |
| Users | identity plus per-product observed/provisioned state | source-specific activity/devices/connections | investigate/access |
| Activity | typed occurrence timeline | source record and lineage | investigate |
| Findings | only admitted finding; show source signal/coverage | detector/evidence/status | triage/remediate |
| Analytics | formula/version/window/coverage | contributing records | optimize/fix coverage |
| Operations | schema/cursor/lag/WAL/reconcile | logs/quarantine | retry/repair/rollback |

Raw diagnostics, credentials, SQL, cache keys, and unrestricted content are operator/restricted surfaces, not customer defaults.
