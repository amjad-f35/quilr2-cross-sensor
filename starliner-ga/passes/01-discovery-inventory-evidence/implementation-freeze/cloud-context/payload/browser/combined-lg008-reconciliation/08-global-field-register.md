# Global Field Register


All 585 Browser-profile source fields are present with native type, meaning, origin, nullability, unit, sensitivity, destination, proof, reachability, disposition, observability, evidence, access recipe, adapter mapping and target support.

No backend-only field is included. Every field belongs to one of the 45 admitted Browser records and appears exactly once in the lineage ledger.
