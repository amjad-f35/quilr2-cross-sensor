# Global Stable-ID Registry


The deterministic UUIDv5 registry contains 26,786 IDs. Source-local declaration identity uses repository + FQN + declaration type + signature + occurrence ordinal; line numbers are locators, not identity. Component-version IDs add the pinned revision and point to logical component IDs.

See [`global-id-registry.yaml`](../../lg008/registries/global-id-registry.yaml) and [`repository-revision-registry.yaml`](../../lg008/registries/repository-revision-registry.yaml).
