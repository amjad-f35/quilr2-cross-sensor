# Authorized-Access Cookbook


There are 978 recipes. Every pinned source file has a safe local Git-blob hash recipe. Each runtime record has an explicit `NO_CURRENT_ACCESS_PATH` recipe because deployment, authorization and live capture authority are not proven.

No credential value or reusable secret appears in a recipe. The runtime recipes require isolated sanitized fixtures and forbid substituting static types/logs for a live capture.

See [`authorized-access-recipes.yaml`](../../lg008/catalogs/authorized-access-recipes.yaml).
